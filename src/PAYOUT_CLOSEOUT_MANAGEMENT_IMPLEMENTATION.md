## Backend Functions

### `adminListPayoutCloseouts`
- Admin-only, read-only
- Filters: `month`, `performer_id`, `status` (all/draft/approved/on_hold/paid)
- Enriches each record with performer name + parsed metadata (generated_by, approved_by, hold_reason, paid_reference, status_history, etc.)
- Returns sorted newest-first

### `adminUpdatePayoutCloseoutStatus`
- Admin-only
- Inputs: `closeout_id`, `action`, `reason`, `paid_reference`, `notes`
- Server-side transition validation with clear error messages
- Records full audit trail in `notes` JSON (status_history array)
- Only updates `status` and `notes` fields — no financial fields touched

**Status Transition Rules:**
```
draft     → approve          ✅
draft     → hold             ✅ (reason required)
approved  → hold             ✅ (reason required)
approved  → mark_paid        ✅ (paid_reference or notes required)
on_hold   → release_hold     ✅ (restores previous_status_before_hold)
any       → revert_to_draft  ✅ (except paid)
paid      → (anything)       ❌ LOCKED
```

Legacy status aliases handled: `"held"` treated as `"on_hold"`, `"pending"/"estimated"` treated as `"draft"`.

## UI Features

**Page:** `/admin/payout-closeouts` → "Payout Closeouts" in Operations nav

**Filters:** Month / Performer / Status — explicit "Load Closeouts" button

**Summary cards:** Total / Draft / Approved / On Hold / Paid (clickable to filter)

**Table columns:** Performer | Month | Performer Share | Studio Share | Sources | Status | Created | Actions

**Expandable detail row:**
- Closeout ID, Generated By
- Revenue Line Item IDs (monospace chips)
- Approved By + date (if applicable)
- Hold Reason (if applicable)
- Payment Reference + paid_by + paid_date (if applicable)
- Admin Notes
- Full Status History audit trail (from → to, by, at, reason)

**Action buttons** (shown per current status):
- Draft: Approve | Put On Hold | Revert to Draft
- Approved: Put On Hold | Mark Paid | Revert to Draft
- On Hold / Held: Release Hold | Revert to Draft
- Paid: 🔒 Locked

**ActionModal:**
- Confirmation text per action
- Reason field (required for hold / revert_to_draft)
- Payment Reference field (required for mark_paid)
- Notes field (always optional; satisfies mark_paid if no ref)
- Warning banner for mark_paid: "No money is transferred by this action"
- Disabled confirm until required fields filled

**Empty state:** Clear message directing to Monthly Closeout Preview → Generate Drafts
