# Creator OS interaction checklist

Implemented states:
- Sidebar navigation: Today, Create, Library, Fans, Money, AI Producer, Calendar, Me update URL query state, active navigation, rendered workspace, and browser history.
- Mission: Begin, open, pause, resume and complete call persisted Creator OS mission actions.
- Today’s Plan: open, complete, undo, edit time, skip and reschedule call persisted plan item actions.
- AI Producer: quick prompts and text input submit to Creator OS AI with performer, mission, briefing, recommendation, revenue, library and fan context; messages persist during the session.
- Recommendation cards: view, convert to mission, save, dismiss and mark acted upon are persisted.
- Intelligence links: fan, library, revenue and series controls open real workspaces.
- Revenue Outlook: opens source period, real revenue, forecast logic, confidence, assumptions and supporting content.
- Momentum rings: open breakdowns for production, fans, revenue and consistency.
- Profile controls: settings, notifications and share open visible profile substates.

Smoke test status: build and backend syntax validation must pass after deployment; visual/manual performer smoke testing should be run with the Testing Agent for screenshots.
