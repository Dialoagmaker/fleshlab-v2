## Attribution and reporting

The browser stores only route, UTM parameters and referrer in the canonical application `answers.attribution` object. It does not use that data for public lookups. The same event stream tracks:

- `creator_page_view`
- `creator_cta_click`
- `creator_application_start`
- `creator_application_complete`

The Growth Analytics API returns an aggregated `recruitment` breakdown by landing route. Administrative reporting must treat qualified applications as the primary KPI; an application becomes qualified only when the existing review workflow has a corresponding qualified/approved status.

## Partner wording

The repository contains no approved xHamster or FapHouse logo asset and no agreement text that authorizes "official", "certified" or "exclusive" language. The public component therefore uses names only under **Distribution & Studio Partners**, with no logo, endorsement or certification claim. Add official artwork only after documented permission and a locally approved source asset are supplied.
